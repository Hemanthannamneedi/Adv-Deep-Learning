# Day 69 – Transformer Decoder

## Overview

Implemented a complete Encoder-Decoder Transformer for English-to-French machine translation using TensorFlow and Keras.

The project demonstrates how a Transformer Decoder generates target sequences using masked self-attention and cross-attention with encoder representations.

## Features

- Custom English-French translation dataset
- Vocabulary creation and tokenization
- Sinusoidal positional encoding
- Transformer Encoder
- Transformer Decoder
- Masked Multi-Head Self-Attention
- Encoder-Decoder Cross-Attention
- Residual Connections
- Layer Normalization
- Feed-Forward Networks
- Teacher Forcing
- Autoregressive Translation
- Training Accuracy and Loss Visualization
- Causal Attention Mask Visualization

## Technologies Used

- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib

## Installation

```bash
pip install -r requirements.txt
```

## Run the Project

```bash
python transformer_decoder.py
```

The script trains the Transformer model, generates French translations, saves model weights, and creates training visualizations.

## Limitations

This is an educational Transformer implementation trained on a small custom dataset. It is not intended for production-level machine translation. French text is simplified by removing accents and apostrophes.

- Built a complete Encoder-Decoder Transformer.
